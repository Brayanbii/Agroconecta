-------------------------------------------------------
¿QUE HICE?
-------------------------------------------------------

Conecte dos tecnologias distintas para que trabajen juntas:
un servidor en PYTHON y una aplicacion en JAVA (Spring Boot).

La idea es que el campesino, cuando va a publicar un producto
en la plataforma AgroConecta, pueda ver los precios de referencia
del mercado colombiano directamente en el formulario, para que
sepa a cuanto esta vendiendo la competencia ese dia.


-------------------------------------------------------
PARTE 1: EL SERVIDOR EN PYTHON (Flask)
-------------------------------------------------------

Cree un servidor web pequeño usando FLASK, que es una libreria
de Python para hacer APIs. Este servidor corre en el puerto 5000
de la misma maquina.

El servidor tiene dos endpoints (direcciones web):

  - http://localhost:5000/api/v1/precios
    Devuelve la lista de precios de productos agricolas
    en formato JSON (como un diccionario de datos).

  - http://localhost:5000/api/v1/precios/estado
    Solo para verificar que el servidor esta encendido.

El servidor intenta primero conectarse al API oficial del SIPSA
(Sistema de Informacion de Precios del Sector Agropecuario)
del DANE, que esta publicado en datos.gov.co con datos reales
del gobierno colombiano.

Si el API del DANE no responde o falla, el servidor activa
automaticamente un modo de simulacion dinamica: usa la hora
actual del sistema como semilla para generar precios aleatorios
que cambian cada hora, simulando el comportamiento real del mercado.

Ejemplo de lo que devuelve el servidor en JSON:

    "status": "success",
    "data": [

PARTE 2: EL MENSAJERO EN JAVA (PythonService)
-------------------------------------------------------

En el proyecto de Spring Boot cree una clase llamada PythonService
con la anotacion @Service (que le dice a Spring que la administre).

Esta clase usa RestTemplate, que es una herramienta de Spring
para hacer peticiones HTTP desde Java hacia otros servidores.

Cuando Java necesita los precios, llama al metodo
obtenerPreciosDesdePython(), que hace una peticion GET
al servidor Python y recibe el JSON como un Map de Java.

Si Python esta apagado, el metodo captura la excepcion y
devuelve null, sin romper la aplicacion.

Codigo resumido:

  @Service
  public class PythonService {
      private final String PYTHON_URL = "http://localhost:5000/api/v1/precios";

      public Map<String, Object> obtenerPreciosDesdePython() {
          try {
              RestTemplate restTemplate = new RestTemplate();
              return restTemplate.getForObject(PYTHON_URL, Map.class);
          } catch (Exception e) {
              return null; // Si Python esta apagado, no pasa nada
          }
      }
  }

-------------------------------------------------------
PARTE 4: LA VISTA EN HTML (Thymeleaf)
-------------------------------------------------------

En el archivo HTML del formulario del campesino, agregue un bloque
que solo aparece si Python esta encendido (usando th:if de Thymeleaf).

El bloque muestra una cuadricula con los precios del dia, el nombre
del producto, el precio en azul y una flecha que indica si el precio
esta subiendo (rojo) o bajando (verde).

Si Python esta apagado, el bloque simplemente no aparece y el
formulario funciona con normalidad. Esto se llama "degradacion
elegante" (graceful degradation).

=======================================================
  PARTE 5: GRAFICOS ESTADISTICOS CON MATPLOTLIB
  (Panel del Administrador)
=======================================================

Ademas de los precios para el campesino, integre una segunda
funcionalidad: el panel del ADMINISTRADOR ahora muestra graficas
estadisticas generadas por Python usando la libreria Matplotlib.

La idea es que el admin pueda ver de un vistazo:
  - Cuales son los productos mas vendidos
  - Cuanto se ha vendido cada mes (en pesos COP)
  - En que estado estan los pedidos (pendiente, entregado, etc.)


-------------------------------------------------------
¿COMO FUNCIONA LA GENERACION DE GRAFICOS?
-------------------------------------------------------

El truco esta en convertir las graficas de Matplotlib a texto
(formato Base64) para poder enviarlas por HTTP como JSON.

Base64 es una forma de representar datos binarios (como una imagen)
usando solo caracteres de texto. Esto permite meterla dentro de un
JSON y enviarla de Python a Java sin necesidad de guardar archivos.

Flujo completo:

  1. Java consulta la base de datos y reune los datos de ventas
  2. Java envia esos datos a Python via HTTP POST (como JSON)
  3. Python recibe los datos y genera 3 graficas con Matplotlib
  4. Python convierte cada grafica a Base64 (texto)
  5. Python devuelve las 3 graficas en Base64 dentro de un JSON
  6. Java recibe el JSON y pasa las imagenes al HTML
  7. Thymeleaf muestra las imagenes en el dashboard del admin


-------------------------------------------------------
PASO A PASO EN PYTHON (servidor.py)
-------------------------------------------------------

Primero, configuramos Matplotlib para que NO abra ventanas
(porque es un servidor, no tiene pantalla):

  import matplotlib
  matplotlib.use('Agg')   # <-- Modo sin pantalla (backend no interactivo)
  import matplotlib.pyplot as plt
  import io, base64

Luego, una funcion auxiliar convierte cualquier figura a Base64:

  def _fig_a_base64(fig):
      buf = io.BytesIO()          # Buffer en memoria (como un archivo temporal)
      fig.savefig(buf, format='png', bbox_inches='tight', dpi=100)
      buf.seek(0)                 # Volver al inicio del buffer
      img_b64 = base64.b64encode(buf.read()).decode('utf-8')
      plt.close(fig)              # Liberar memoria
      return img_b64

El endpoint POST recibe los datos y genera las 3 graficas:

  @app.route('/api/v1/graficos', methods=['POST'])
  def generar_graficos():
      datos = request.get_json()

      # --- GRAFICA 1: Barras horizontales - Top productos ---
      productos = datos.get('productos', [])
      nombres   = [p['nombre']   for p in productos]
      cantidades = [p['cantidad'] for p in productos]

      fig1, ax1 = plt.subplots(figsize=(8, 4))
      ax1.barh(nombres, cantidades, color='#16a34a')
      ax1.set_title('Top Productos Mas Vendidos')
      grafico_productos = _fig_a_base64(fig1)

      # --- GRAFICA 2: Barras verticales - Ventas por mes ---
      ventas = datos.get('ventas_mes', [])
      meses  = [v['mes']   for v in ventas]
      totales = [v['total'] for v in ventas]

      fig2, ax2 = plt.subplots(figsize=(10, 4))
      ax2.bar(meses, totales, color='#16a34a')
      ax2.set_title('Ventas por Mes (COP)')
      grafico_meses = _fig_a_base64(fig2)

      # --- GRAFICA 3: Torta - Estado de pedidos ---
      estados = datos.get('estados', [])
      labels  = [e['estado']   for e in estados]
      sizes   = [e['cantidad'] for e in estados]

      fig3, ax3 = plt.subplots(figsize=(6, 6))
      ax3.pie(sizes, labels=labels, autopct='%1.1f%%')
      ax3.set_title('Estado de Pedidos')
      grafico_estados = _fig_a_base64(fig3)

      return jsonify({
          'status': 'success',
          'grafico_productos': grafico_productos,
          'grafico_meses':     grafico_meses,
          'grafico_estados':   grafico_estados
      })


-------------------------------------------------------
PASO A PASO EN JAVA (PythonService.java)
-------------------------------------------------------

Se agrego un segundo metodo al PythonService para hacer el POST:

  public Map<String, Object> generarGraficos(Map<String, Object> datos) {
      try {
          RestTemplate restTemplate = new RestTemplate();

          // Configurar cabecera Content-Type: application/json
          HttpHeaders headers = new HttpHeaders();
          headers.setContentType(MediaType.APPLICATION_JSON);

          // Empaquetar datos + cabeceras en un HttpEntity
          HttpEntity<Map<String, Object>> request = new HttpEntity<>(datos, headers);

          // POST a Python y recibir el JSON de respuesta
          return restTemplate.postForObject(GRAFICOS_URL, request, Map.class);

      } catch (Exception e) {
          System.out.println("Error: Python apagado (graficos).");
          return null;  // Si Python esta apagado, el dashboard carga sin graficas
      }
  }

La diferencia con el GET de precios es que aqui usamos:
  - HttpHeaders: para decirle a Python que enviamos JSON
  - HttpEntity:  para empaquetar el cuerpo + las cabeceras juntos
  - postForObject: en lugar de getForObject (es un POST, no un GET)

PASO A PASO EN JAVA (DashboardController.java)
-------------------------------------------------------

El controlador del admin hace 3 consultas a la base de datos
y las empaqueta en un Map para enviarselas a Python:

  // 1. Top productos mas vendidos (desde DetalleOrden)
  List<Map<String, Object>> productos = new ArrayList<>();
  for (Object[] row : detalleRepo.findTopProductos()) {
      Map<String, Object> item = new HashMap<>();
      item.put("nombre",   row[0]);   // Nombre del producto
      item.put("cantidad", row[1]);   // Unidades vendidas
      item.put("total",    row[2]);   // Total en pesos
      productos.add(item);
  }

  // 2. Ventas por mes (desde Orden)
  List<Map<String, Object>> ventasMes = new ArrayList<>();
  String[] meses = {"Ene","Feb","Mar","Abr","May","Jun",
                    "Jul","Ago","Sep","Oct","Nov","Dic"};
  for (Object[] row : ordenRepo.findVentasPorMes()) {
      Map<String, Object> item = new HashMap<>();
      int mesNum = ((Number) row[0]).intValue();
      item.put("mes",   meses[mesNum - 1]);  // Convierte 1 -> "Ene"
      item.put("total", row[1]);
      ventasMes.add(item);
  }

  // 3. Estado de pedidos (desde Orden)
  List<Map<String, Object>> estados = new ArrayList<>();
  for (Object[] row : ordenRepo.findOrdenesPorEstado()) {
      Map<String, Object> item = new HashMap<>();
      item.put("estado",   row[0] != null ? row[0] : "Sin estado");
      item.put("cantidad", row[1]);
      estados.add(item);
  }

  // 4. Enviar todo a Python y recibir las graficas
  Map<String, Object> datosPython = new HashMap<>();
  datosPython.put("productos",  productos);
  datosPython.put("ventas_mes", ventasMes);
  datosPython.put("estados",    estados);

  Map<String, Object> graficos = pythonService.generarGraficos(datosPython);
  if (graficos != null) {
      model.addAttribute("graficoProductos", graficos.get("grafico_productos"));
      model.addAttribute("graficoMeses",     graficos.get("grafico_meses"));
      model.addAttribute("graficoEstados",   graficos.get("grafico_estados"));
  }

CONSULTAS JPA NUEVAS (Repositorios)
-------------------------------------------------------

Para obtener los datos de ventas, se agregaron consultas JPQL
(el lenguaje de consultas de JPA/Hibernate, similar a SQL):

En DetalleOrdenRepository.java:

  @Query("SELECT d.nombre, SUM(d.cantidad) AS totalCantidad, " +
         "SUM(d.total) AS totalVentas " +
         "FROM DetalleOrden d " +
         "GROUP BY d.nombre " +
         "ORDER BY totalCantidad DESC")
  List<Object[]> findTopProductos();

En OrdenRepository.java:

  @Query("SELECT MONTH(o.fecha), COUNT(o) " +
         "FROM Orden o GROUP BY MONTH(o.fecha) ORDER BY MONTH(o.fecha)")
  List<Object[]> findVentasPorMes();

  @Query("SELECT o.estado, COUNT(o) FROM Orden o GROUP BY o.estado")
  List<Object[]> findOrdenesPorEstado();

PASO A PASO EN HTML (dashboard_admin.html - Thymeleaf)
-------------------------------------------------------

Las imagenes Base64 se muestran con una etiqueta <img> especial.
En lugar de poner una URL, se pone directamente el contenido
de la imagen codificado en Base64:

  <!-- Grafica 1: Top productos -->
  <div th:if="${graficoProductos}">
      <img th:src="'data:image/png;base64,' + ${graficoProductos}"
           class="w-full rounded-lg" />
  </div>

  <!-- Grafica 2: Ventas por mes -->
  <div th:if="${graficoMeses}">
      <img th:src="'data:image/png;base64,' + ${graficoMeses}"
           class="w-full rounded-lg" />
  </div>

  <!-- Grafica 3: Estado de pedidos -->
  <div th:if="${graficoEstados}">
      <img th:src="'data:image/png;base64,' + ${graficoEstados}"
           class="w-full rounded-lg" />
  </div>

  <!-- Si Python esta apagado, muestra aviso amarillo -->
  <div th:if="${graficoProductos == null and graficoMeses == null
               and graficoEstados == null}">
      ⚠ Python esta apagado. Las graficas no estan disponibles.
  </div>

El navegador entiende "data:image/png;base64,..." como una imagen
PNG directamente incrustada en el HTML, sin necesidad de archivos.
